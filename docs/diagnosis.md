# SENTINEL Failure Diagnosis Engine

Supported Diagnosis Types:
- `PROMPT_QUALITY`
- `PROMPT_AMBIGUITY`
- `RETRIEVAL_FAILURE`
- `KNOWLEDGE_GAP`
- `MODEL_WEAKNESS`
- `HALLUCINATION`
- `FAITHFULNESS_FAILURE`
- `CONSISTENCY_FAILURE`
- `TOXICITY`
- `LATENCY`
- `UNKNOWN`

Diagnoses are evidence-based multi-signal output objects containing confidence, evidence dict, and auto-healing compatibility flags.
